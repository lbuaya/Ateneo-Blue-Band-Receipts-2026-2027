Setup Guide

Google Sheet Template Setup

Follow these steps to connect the Google Sheet to the ABB Receipt Generator so receipts are automatically recorded.

Steps 1 – 5  ·  Initial Setup
1
Copy the Template
Open the Google Sheet template. Go to File → Make a copy. In the dialog that appears, rename it if you like, then click Make a copy to save it to your own Google Drive.
Tip: Keep Share it with the same people checked so existing collaborators retain access on the copied sheet.
File → Make a copy · then confirm in the Copy document dialog
2
Change Sharing Settings
In your copied sheet, click Share (top-right). Change the general access from Restricted to Anyone with the link, and set the role to Editor. This allows the Apps Script web app to write data to the sheet.
Why Editor? The script submits receipt data as a new row. Without Editor access, the POST request will be rejected.
Set access to "Anyone with the link – Editor"
3
Open Apps Script
Inside the copied Google Sheet, go to the menu bar and click Extensions → Apps Script. This opens the Apps Script editor in a new tab where the backend script (Code.gs) is already pre-loaded.
Note: You should see a doPost(e) function already written. Do not modify the script — it is already configured for this system.
Extensions → Apps Script
4
Open the Deploy Menu
In the Apps Script editor, click the Deploy button in the top-right corner. A dropdown will appear with several deployment options — you'll choose New deployment in the next step.
Click the "Deploy" button (top-right of the editor)
5
Select "New Deployment"
A dropdown appears with three options: New deployment, Manage deployments, and Test deployments. Click New deployment to create a fresh deployment with its own unique URL.
Important: Always choose New deployment — not Manage deployments — when setting this up for the first time.
Click New deployment from the Deploy dropdown
Steps 6 – 10  ·  Finalize & Connect
6
Configure & Deploy the Web App
The New deployment dialog opens. Under Select type, confirm it says Web app. Then open the Who has access dropdown and select Anyone — this allows the receipt generator to send data without needing a Google login. Once set, click the blue Deploy button.
Note: "Execute as" should stay as Me (your own Google account). Only change "Who has access" to Anyone.
Select type: Web app · Who has access: Anyone · then click Deploy
7
Authorize Access
A dialog will appear saying "The Web App requires you to authorize access to your data." Click the blue Authorize access button to proceed. This is required for the script to write data to your Google Sheet.
Click Authorize access to grant the script permission
8
Allow Access on the Google Consent Screen
Google will open a consent screen in a new browser window. It will show that Sample Sheet is requesting permission to "See, edit, create, and delete all your Google Sheets spreadsheets." Review the permissions, then click Continue to grant access and complete authorization.
Why this access? The script needs permission to append rows to your sheet every time a receipt is generated.
Click Continue on the Google consent screen to authorize
9
Copy the Web App URL
After authorization, the New deployment dialog will confirm: "Deployment successfully updated." Under the Web app section, you'll see the generated URL (a long script.google.com/macros/s/… link). Click Copy next to it, then click Done to close the dialog.
Keep this URL! You'll need to paste it into the receipt generator in the next step. Don't close the tab before copying.
Click Copy under Web app URL · then click Done
10
Paste the URL into the Receipt Generator
Return to the Receipt Encoder. Scroll to the Google Sheets Setup section. You'll see a field labelled Google Apps Script URL with the placeholder text "Paste your web app URL here." Click the field and paste the URL you copied in Step 9. The generator will now automatically record every printed receipt directly into your Google Sheet.
Done! Once the URL is saved, the connection is live — no need to set this up again unless you redeploy the script.
Paste the Web App URL into the Google Apps Script URL field
✅ You're all set! Once the URL is saved in the receipt generator, every receipt you print will automatically send a record to your Google Sheet — including the invoice number, name, grade, payment type, items, and total.

Now that your sheet is connected, check out the Receipt Encoding Guide to learn how to generate, save, and print receipts.
